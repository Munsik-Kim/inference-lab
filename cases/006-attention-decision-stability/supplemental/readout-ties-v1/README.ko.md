# Case 006 보충: 동률과 출력 head 정밀도

원래 표준 192개 입력에서 A_PUBLIC의 선택 변화 5건과 V4의 8건은 모두 기준 또는 후보의 최고 점수 동률을 포함했다. 기준·후보가 모두 단독 최고값을 가진 경우에는 native 선택 변화가 없었다. 동률 처리도 실제 측정 시스템의 동작이므로 이 결과를 무효로 취급하지 않는다.

동일한 마지막 정규화 hidden state와 BF16에 표현된 가중치를 FP32로 올려 전체 vocabulary head를 다시 계산했다. 새 입력이나 FP32 전체 모델 실험이 아니다. 이 그림자 readout에서는 최고값 동률이 없어지고 후보별 선택 변화는 각각 3건이었다. 기존 변화 일부가 사라졌지만 새 변화도 생겼다. 표준 집합의 A_PUBLIC에는 FP32 기준 대비 정답→오답 1건이 나타났다. FP32를 더 좋은 운영 설정으로 추천하지 않는다.

714개 셀의 네 선택지 점수는 FP32→BF16 반올림 시 원래 값과 모두 일치했다. 그러나 전체 vocabulary 벡터는 어느 셀도 완전히 같지 않았다. 선택지에서는 출력 반올림 영향과 일치하는 증거가 있지만, GEMM 계산 경로 차이까지 전부 반올림으로 설명할 수 없다.

B hidden state 238개를 재사용했고 후보 476개만 한 번씩 replay했다. smoke는 6회였다. 모든 replay의 전체 native logits가 원본과 정확히 같았다. 새 생성·시간 측정은 하지 않았다. 기존 JSON 생성 0/24, 기존 약 0.4%/0.14% 모델-prefill 시간 변화와 배포 판단 NOT_ASSESSED는 그대로다.
