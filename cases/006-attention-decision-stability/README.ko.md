# Case 006: 저정밀 attention과 답변 선택의 안정성

RTX 5080에서 같은 Qwen3-0.6B 모델의 13번 층 prefill attention만 바꾸고, 같은 문제에 대한 답과 정답 확률이 어떻게 달라지는지 측정했다. 나머지 층, 모델 가중치, 이후 토큰 생성은 BF16으로 유지했다.

표준 평가 192개에서 BF16은 104개, A_PUBLIC은 106개, V4는 108개를 맞혔다. A_PUBLIC/V4에서 선택이 바뀐 항목은 5개/8개였다. 그중 정답으로 바뀐 것은 2개/4개, 다른 오답으로 바뀐 것은 3개/4개였다. 이 표준 집합에는 정답→오답 변화가 없었지만, 별도로 선정한 경계 스트레스 46개에서는 각각 2개/1개가 발생했다.

평균 정답 NLL 변화는 A_PUBLIC +0.00109 nats, V4 −0.00718 nats였고 두 불확실성 구간 모두 0을 포함했다. 이를 일반적인 품질 개선이나 품질 보존의 증거로 쓰지 않는다. 국소 attention 오차가 더 작은 설정이 모든 답변에서도 더 낫다는 결론도 내리지 않는다.

기준 모델의 과제별 정답은 검색 59/64, 비교 30/64, 코드 15/64였다. 특히 코드 과제의 낮은 기준 성능이 해석을 제한한다. 별도 24개 입력의 JSON 생성 진단은 세 설정 모두 엄격한 형식을 통과하지 못했다. 형식을 고치거나 실패 응답을 제외하지 않았다.

[오프라인 근거 탐색기](demo/index.html)는 실제 입력, 정답, 세 설정의 확률, 유효성, 항목별 변화를 보여준다. HTML을 내려받아 브라우저에서 연다. 외부 서버는 필요 없지만 JavaScript를 막는 파일 미리보기나 태블릿에서의 동작은 별도로 확인하지 않았다.

[영어 결과와 모델 시간 측정](README.md), [분석](ANALYSIS.md), [재계산 명령](REPRODUCTION.md), [포트폴리오 카드](PORTFOLIO.md)를 함께 제공한다. 저장된 수치의 독립 계산 검증은 수행했지만 제3자가 GPU 실험을 재현했다는 뜻은 아니다. 배포 판단은 `NOT_ASSESSED`이며, 이전 Case005의 `STOP_DEV_SCREEN` 결과도 바꾸지 않는다.

## 사후 보충: 동률과 출력 head
