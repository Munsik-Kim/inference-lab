What are loops and steps?

A step advances the noisy image toward its final form. Loops reuse the same core blocks inside each step. B/32 means a 32-pixel patch size, not 32 loops.

L=1 uses the same checkpoint trained at four loops. All settings keep 512px, Euler, CFG=6, a BF16 denoiser and FP32 T5.

Comparison

Timing-only DEV requests selected configurations near the L=4/S=50 reference time. Image quality was not used for selection. MAIN generates the same 64 prompt–seed pairs (16 prompts × four seeds) at three settings.

Block proxy and actual call counts

CFG=6: model calls = 2S; joint block visits = 2S(12+5L). Proxy A/B/C: 3,196 / 3,212 / 3,200. These are not equal FLOPs or latency. Text preamble, embeddings, output heads, T5 and transfers are outside the proxy.
