# §8A. v1 보존 기록의 모델 없는 재분석

원래 독립 감사기를 새 출력 위치에서 다시 실행하여 toy 현재 기록 125개, 학습 기록 78개, 추가 혼합 배분 12개를 확인했다. 모두 통과했다. 학습이나 모델 추론, checkpoint 로딩, GPU 계산을 실행하지 않았다. 감사 범위는 보존된 정답 비트, 최초 실패 시점, 스칼라·신뢰구간 끝점, 실제 공유 버퍼와 저장량 공식, 원본 hash 대응이다. 없는 최종 상태 배열의 실제 byte나 checkpoint 파일을 다시 검증한 것으로 해석하지 않는다. 공개용 receipt에는 논리적 상대 경로만 포함한다.

재분석은 원래 TEST 입력과 seed별 512개 분모를 그대로 유지한다. 세 모델 seed를 합쳐 표본수를 늘리지 않는다. 최초 실패 이후 회복이나 비유한 상태 실패를 제외하거나 다시 성공으로 계산하지 않는다. `tau=None`은 제한 길이 2,048을, 관측 실패 시점은 `tau−1`을 평균 연속 정답 길이에 기여한다. 90개 arm 기록에서 이 계산을 정답 비트와 다시 대응시켰다.

## 주 결과와 역사적 비교 범위

**추가 혼합 배분을 포함한 최종 30-arm, joint630 비교에서 supported 5% horizon을 높인 잔차 후보는 0/54로 유지된다.** 54는 잔차 여섯 설정 × 모델 세 seed × N=1/16/128의 조합이다. 이는 신뢰 하한의 기술통계 순서이며 우월성 검정이 아니다.

보충 전 26-arm, family546 표에는 2/54의 하한 개선이 있다. 둘 다 seed0의 rank1이며 N=16과128에서 UNIFORM4의32보다64가 높았다. 원래 최종 v1 결론의0/54는 더 강한 추가 혼합 기준선을 포함한 표에 해당한다. 이 두 역사적 표를 혼동하지 않는다.

저장량은 `shared_bytes + N × per_stream_bytes`로 다시 계산했다. 같은 한도에서 가장 큰 TEST RMST를 보인 기준선의 선택은 사후적이며, `all_30arm_byte_ledgers.csv`는90개 arm의 N=1/16/128 합계와 원래 joint630 하한을 보존한다. 공통 모델 가중치와 임시 작업 공간은 이 캐시 한도에 포함되지 않는다.

## 짝지은 RMST 차이

동일 sequence ID의 후보와 기준선을 짝지어 seed마다512개 쌍을 재표집했다. 반복은5,000회, master seed는41001, seed별 난수는 `SeedSequence([41001, model_seed])`이다. 구간은 bootstrap 분위수2.5%와97.5%의 선형 보간으로 계산한다. 비교마다 같은 seed별 재표집 인덱스를 사용한다. 아래는 N=128의 후보−기준선 차이다.

| 후보 / 기준선 | 모델 seed | RMST 차이(token) | 점별95% bootstrap 구간 |
|---|---:|---:|---:|
| rank1 / MIXED4/8 TOP2 |0|−7.62|[−15.15, 0.08]|
| rank1 / MIXED4/8 TOP2 |1|−6.68|[−15.42, 2.06]|
| rank1 / MIXED4/8 TOP2 |2|−2.85|[−8.69, 2.86]|
| rank2 / UNIFORM5 |0|47.07|[35.69, 59.02]|
| rank2 / UNIFORM5 |1|6.54|[−2.58, 16.23]|
| rank2 / UNIFORM5 |2|10.28|[4.45, 16.03]|

이 구간은 **재사용한 TEST에서 이미 고른 기준선을 고정한 조건부·점별·사후 구간**이다. 기준선 선택 불확실성과54개 비교의 다중성을 보정하지 않았다. 독립 확인, 모든 seed의 개선, 모집단 우월성, 또는 주 지표의 성공을 뜻하지 않는다. 전체54개 비교는 `paired_rmst_bootstrap.csv`에 있다. rank2의 양의 평균 차이가 supported 5% horizon 개선으로 바뀌지 않는 기존 결론을 유지한다.

## 그림·재현·독립 검토 문서

`historical_v1_30arm_budget.png`와 PDF는 추가 혼합 네 설정을 포함한30개 arm을 표시한다. 행은 모델 seed, 열은 N=1/16/128이다. 각 점은 joint630 보존 CSV의 실제 저장량과 RMST이며, 동일 TEST를 다시 본 사후 그림이다. 어떤 점도 새로운 모델 실행의 결과가 아니다.

`analysis/v1_reanalysis.py --v1 <v1 case directory> --output <new directory>`로 원본 감사와 표·그림을 다시 생성할 수 있다. 두 번의 생성에서 네 수치 CSV,186개 source hash 목록, 원본 감사 receipt 두 개가 byte 단위로 일치했다. censoring 경계, sequence ID 짝짓기, 상수 효과의 구간, 난수 재현성·부호 대칭, 부적절한 입력, 공개 receipt 경로 검사를 포함한 독립 소규모 테스트6개가 통과했다.

요청된 `CASE010_REVIEW_KO.md`, `diova_case010_independent_review_20260923.zip`, `probe_restart_failure.py`는 접근 가능한 작업·다운로드·임시·Codex 자료 영역의 정확한 파일명 검색에서 찾지 못했다. 접근 불가능하거나 원격에만 있는 첨부에 대한 부재 판정은 아니다. 따라서 검토 문서의 수치나 script 결과를 검증된 사실로 채택하지 않았다. 검색 범위와 상태는 `review_artifact_availability.json`에 남겼다.
