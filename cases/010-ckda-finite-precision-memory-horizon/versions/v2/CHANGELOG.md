# Change log

## 2026-09-23 — failure-aware v2 follow-up

- Added the separate `research/case010-failure-aware-v2/` study. Original v1 archive, results and upstream sources remain unchanged. Reference source copies are identified byte-for-byte in [v1_source_identity.json](provenance/v1_source_identity.json).
- Extended the serialized stream header from the original eight-byte cursor to a 17-byte header: cursor, terminal code and first terminal write. Detected numerical state failures preserve the last committed body and RNG bytes, consume the write cursor, and keep subsequent outputs invalid. Programming errors, malformed inputs, corrupt checkpoints, crashes and resource failures remain execution errors.
- Kept wrong finite labels separate from runtime terminal state. Finite-state nonfinite readout produces an invalid prediction while allowing the finite state to continue. BOS is a consumed write but is excluded from scored first failure.
- Added atomic-visibility evaluation-job checkpoints with cumulative prediction/correctness/gold history, original sample order, first-failure history and counters. These evaluator files are separate from charged cache bytes. They retain prior errors across resume; they do not promise fsync crash durability.
- Added synthetic byte-codec and fresh-process restart tests, including stochastic RNG continuation and before/after-terminal boundaries. Added independent scalar/audit tests and a runner boundary test for resume after an already-consumed BOS.
- Added model-free reanalysis of retained v1 observations, with separate original/supplemented confidence families, seed-specific paired bootstrap diagnostics, full-token empirical horizons and actual byte-ledger tables. Re-extracted the original archive and reran its publication verifier and original CPU tests; the [receipt](provenance/v1-restored-verification.json) distinguishes this rerun from the earlier unique-test total.
- Froze the narrow fresh comparison and new byte-budget mixed comparator before full fresh inference. The [protocol](protocol_v2.json) specifies the same three checkpoints, a separate 1,024-input cohort, five arms, 195 grid comparisons and three prescribed input-paired comparisons per model seed. The comparator reuses retained CAL scores and basis data without refitting.
- Added four fixed-coefficient transition/readout precision modes and scalar-only native/FP64-shadow traces on the separate diagnostic cohort. Added bounded historical full/chunk/fresh-process replay and isolated serial CPU complete-call timing entry points.
- Added [audit_v2.py](analysis/audit_v2.py) and [aggregate_v2.py](analysis/aggregate_v2.py). Full aggregation requires all 15 fresh cells and a passing independent audit. Partial validation explicitly reports incompleteness and never silently reduces the family or denominator.
- Corrected two runner bookkeeping issues before full fresh execution: byte accounting now uses the actual final batch, and resume determines BOS inclusion from absence of a restored state. These changes do not modify the frozen scientific protocol or a completed observation.
- The [71-file freeze](provenance/protocol_freeze.json) covers the critical runtime and frozen data/configuration. Orchestration/report code is identified separately in attempt records and runner receipts. No package installation or upgrade, new training, model upload or GPU inference was performed by these additions; actual execution status belongs to the corresponding receipts and final study report.

The unavailable independent-review files were not treated as verified sources. The retained synthetic v1 probe is explicitly prompt-based. This change log describes implementation and provenance; it does not substitute for final results or make a new superiority claim.
