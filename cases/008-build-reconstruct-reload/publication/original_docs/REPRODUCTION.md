Run repository-relative commands from the repository root. A review ZIP keeps `tools/modelpack/` and `cases/008-build-reconstruct-reload/` at the same relative locations. Older case links refer to the repository. Choose **new external output directories**; code refuses to overwrite successful results. Public weights are not included.

## CPU analysis

The tested CPU environment is Python 3.12, NumPy 2.3.5 and Matplotlib 3.10.8. Artifact tests additionally use the pinned Torch 2.13.0, Transformers 5.17.0 and safetensors 0.8.0 environment. Use an existing compatible interpreter as `$CPU_PY`; these commands do not download a model.

```bash
CASE=cases/008-build-reconstruct-reload
"$CPU_PY" -B -m unittest discover -s "$CASE/tests" -v
"$CPU_PY" -B -m tools.modelpack.analysis --case "$CASE" --output "$NEW_ANALYSIS"
"$CPU_PY" -B -m tools.modelpack.audit --case "$CASE" \
  --summary "$NEW_ANALYSIS/summary.json" --output "$NEW_AUDIT_JSON"
"$CPU_PY" -B -m tools.modelpack.report --case "$CASE" --output "$NEW_REPORT"
"$CPU_PY" -B -m tools.modelpack.package verify
```

The planned split-separated recovery and same-size cost tables, plus the separate timing checker, use the same preserved records:

```bash
"$CPU_PY" -B "$CASE/scripts/additional_tables.py" --case "$CASE" --output "$NEW_TABLES_JSON"
"$CPU_PY" -B "$CASE/scripts/local_tables.py" --case "$CASE" --output "$NEW_LOCAL_TABLES_JSON"
"$CPU_PY" -B "$CASE/scripts/check_timing.py" --case "$CASE" \
  --summary "$NEW_ANALYSIS/summary.json" --output "$NEW_TIMING_AUDIT_JSON"
"$CPU_PY" -B "$CASE/scripts/plot_score_boundaries.py" \
  --summary "$NEW_ANALYSIS/summary.json" --output "$NEW_SCORE_FIGURE_PNG"
```

`report` regenerates the original primary-score figure, recovery figure and English HTML. The extra score-boundary figure shows full-vocabulary NLL and conditional choice NLL together. Editorial README/ANALYSIS prose is not generated byte-for-byte by that report command. `validation.json` records numerical/byte comparisons and the actual browser test separately from the generator's earlier `NOT_RUN` marker.

Analysis uses public option logits, full-vocabulary normalizers, saved full-KL scalars and local norm statistics. The separate scalar checker recomputes option scores, correctness transitions, paired means/intervals and recovery ratios. It cannot recover excluded full logits, hidden vectors, weights or kernel traces from those scalars. The tiny randomly initialized model in the tests is a labelled fixture, separate from measured result tables.

Open `demo/index.html` directly to explore saved results without a GPU or server. The UI is English. Browser execution and real-iPad verification are reported separately in validation; an HTML source preview on GitHub is not an executing demo.

## Local source and artifact inspection

`$Q_SNAPSHOT` and `$R_SNAPSHOT` must point to the existing pinned local snapshots, not an arbitrary newer checkpoint. `$GPU_PY` is the unchanged serving/native environment. `$BUILD_PY` is the isolated compressor environment described in provenance. GPU commands below require the measured device and sufficient free resources; they are not part of CPU reanalysis.

```bash
"$GPU_PY" -B -m tools.modelpack inspect --snapshot "$R_SNAPSHOT" \
  --revision c1899de289a04d12100db370d81485cdf75e47ca --output "$NEW_SOURCE_JSON"
"$GPU_PY" -B -m tools.modelpack inspect-artifact --artifact "$PRIVATE_ARTIFACT" \
  --output "$NEW_INSPECTION_JSON"
"$GPU_PY" -B -m tools.modelpack reload-test --artifact "$PRIVATE_R_ARTIFACT" \
  --input "$CASE/inputs/R/smoke.json" --device cuda --output "$NEW_RELOAD_JSON"
```

R reload constructs a config-based skeleton with the declared layer-13 width, strictly assigns standalone safetensors, restores tied embeddings and derives rotary buffers. It never reads the original checkpoint. Q uses a standard compressed-tensors checkpoint and the separate vLLM runtime; its reload command is the smoke evaluation below.

## Q build and execution

The pinned build recipe is implemented in `tools/modelpack/quantized.py`; no alternative quantizer or recipe search is performed. Build and serving dependencies differ deliberately. Do not run the inherited vLLM package in the compressor environment.

```bash
"$BUILD_PY" -B -m tools.modelpack build-q --snapshot "$Q_SNAPSHOT" --output "$NEW_Q_BUILD"
"$GPU_PY" -B -m tools.modelpack evaluate --track Q --artifact "$PRIVATE_Q_COPY" \
  --split smoke --output "$NEW_Q_RELOAD"
"$GPU_PY" -B -m tools.modelpack evaluate --track Q --artifact "$PRIVATE_Q_COPY" \
  --split heldout --output "$NEW_Q_EVAL"
"$GPU_PY" -B -m tools.modelpack benchmark --track Q --artifact "$PRIVATE_Q_COPY" \
  --round 1 --output "$NEW_Q_TIMING"
```

`qartifact.finalize(build_path, output_path)` adds a standalone artifact manifest to a byte-identical tensor copy of the built standard checkpoint. The two reload processes use another verified copy. Source/tokenizer hashes and both process results must match before evaluation advances. The measured vLLM compatibility flags, fixed KV cache, full-output checks and profiler scope are explicit in `q_runtime.py`.

## R reconstruction and execution

```bash
"$GPU_PY" -B -m tools.modelpack.r_study smoke --snapshot "$R_SNAPSHOT" --output "$NEW_R_SMOKE"
"$GPU_PY" -B -m tools.modelpack.r_study calibrate --snapshot "$R_SNAPSHOT" --output "$NEW_R_CAL"
"$GPU_PY" -B -m tools.modelpack.r_study develop --snapshot "$R_SNAPSHOT" \
  --calibration "$NEW_R_CAL" --output "$NEW_R_DEV"
"$GPU_PY" -B -m tools.modelpack.r_study export --snapshot "$R_SNAPSHOT" \
  --calibration "$NEW_R_CAL" --development "$NEW_R_DEV" --output "$NEW_R_ARTIFACTS"
"$GPU_PY" -B -m tools.modelpack.r_study calibration-readout \
  --calibration "$NEW_R_CAL" --development "$NEW_R_DEV" --output "$NEW_R_CAL_READOUT"
"$GPU_PY" -B -m tools.modelpack evaluate --track R --artifact "$PRIVATE_R_COPY_ROOT" \
  --arm R-B --output "$NEW_R_BASELINE"
"$GPU_PY" -B -m tools.modelpack evaluate --track R --artifact "$PRIVATE_R_COPY_ROOT" \
  --arm I25-R --baseline "$NEW_R_BASELINE" --output "$NEW_R_CANDIDATE"
"$GPU_PY" -B -m tools.modelpack benchmark --track R --artifact "$PRIVATE_R_COPY_ROOT" \
  --round 1 --output "$NEW_R_TIMING"
```

The fixed arms are R-B, I25, I25-R, P25, P25-R, S50 and S50-R. Repeat reload in two separate processes for each artifact, and use all three numbered timing rounds. Calibration-readout reuses exact stored full-shape H and runs only the smaller down projection; it is not another transformer pass.

With the excluded calibration H/Y vectors and selected solutions present, `scripts/check_private_fit.py --help` describes an additional CPU FP64 fit check. It recomputes sufficient statistics and uses a direct solve to compare with the Cholesky result. Public scalar records alone cannot run this check. Artifact JSON files describe their state at export time; later reload/quality/cost completion is recorded in the case's `RUN_STATE.json` and validation, without rewriting those historical artifact manifests.

Evaluation checks the recorded local freeze. Reproducing the same frozen study does not create new unseen data. A changed implementation, data set or recipe needs a separately recorded version and protocol, not a rewritten historical freeze. Private append-only execution logs and next-command records permit explicit resume after inspection; successful output directories are not silently replaced.
