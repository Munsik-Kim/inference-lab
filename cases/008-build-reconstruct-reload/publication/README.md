# Current publication and historical experiment

[Report](../REPORT.md) · [한국어 보고서](../REPORT.ko.md) · [Commands](../REPRODUCTION.md)

The original review archive has **105 files**: 85 case files, 19 modelpack Python sources and the root license. Its SHA256 is `49cc2640b63d7662cf3d40c168eaf036505bbf5f7f5f73de8de48099d452daca`. [Original inventory](original_inventory.json) is independently pinned in the current verifier; updating the current manifest cannot hide a changed measurement or original source.

Six editorial documents retain their reviewed bytes under [original_docs](original_docs/). [change_record.json](change_record.json) maps original and published hashes and enumerates additions. Original inputs, freezes, raw/derived results, modelpack code, scientific tests, figures, HTML, provenance and RUN_STATE remain unchanged. RUN_STATE's historical `LOCAL_REVIEW_CANDIDATE_NOT_PUBLISHED` describes that snapshot, not today's GitHub branch or merge state. [status.json](status.json) describes this publication package; the actual remote commit/PR receipt is outside the package to avoid self-reference.

`verify_publication.py` checks current inventory/checksums, anchored original hashes, editorial exceptions, source mappings, report table values and post-hoc scalar consistency. `restore_original.py` creates a new tree with **only** the original case, code and license. There the unmodified `tools.modelpack.package verify` and original CPU tests can run. The expanded public tree intentionally does not satisfy the old exact file inventory.

The [post-hoc directory](posthoc/) contains task-wise NLL/mass, constant-label and generator-cue calculations from the same inputs. `review_metrics.py` adapts the supplied user's review script **only at its path/output interface**. Its JSON was reproduced byte-for-byte; an additional stdlib implementation recalculates option scores and joins against frozen inputs. Display tables are generated by [tables.py](tables.py) and compared to both reports. These are calculation checks, not independent GPU replication.

The public manifest uses repository-relative paths and covers the case, original modelpack sources and root license, excluding itself. The ZIP's hash lives only in external download metadata. Cross-case/source navigation beyond these files needs the full repository. Large model weights, private H/Y, full logits, cache and environment files are not distributed.
