# Case021 execution contract

This is a local inference diagnostic of an existing D16 artifact. It neither
quantizes a checkpoint nor reproduces the paper's reinforcement learning runs.
The frozen experiment specification is [protocol.json](protocol.json).

## What is held constant

Qwen/Qwen3-0.6B revision `c1899de289a04d12100db370d81485cdf75e47ca`;
196 existing group64 projection artifacts; signed codes, gamma, alpha inverse
and beta inverse; all non-quantized modules; BF16 activations; batch1; native
HF SDPA; inference mode; eager execution; no cache, sampling or generation.
Every forward computes all N positions through lm_head (`logits_to_keep=0`).
Only afterward are 16 full-vocabulary rows retained. Token position i predicts
input token i+1. N=128 is a prefix of the same document's N=512 input.

All 196 actual projection biases are absent. The exact synthetic mapping
fixture additionally exercises a nonzero bias. Dense fused epilogue and a
packed post-add would be different execution contracts if bias were present.

## D0, D1 and P

Let codes have shape [O,I], group size64 and G=I/64. Gamma and alpha inverse
are [O,G], beta inverse is [I]. Actual scales are stored FP32 in these artifacts.

| Path | Reconstruction / execution |
|---|---|
| D0 PRIMARY_DENSE | `blocks=codes.to(scale_dtype).reshape(O,G,64)`; `pre=(blocks*gamma[...,None])*alpha_inv[...,None]`; reshape and cast BF16; original dense `F.linear` contract |
| D1 PACKED_FORMAT_DENSE | `s16=BF16(FP32(alpha_inv)*FP32(gamma))`; `W1=BF16(FP32(codes)*FP32(s16)[...,None])`; dense `F.linear` |
| P MARLIN_PACKED | signed c becomes c+8, transposed [I,O], packed eight nibbles per int32; `gptq_marlin_repack`; [G,O] combined BF16 scales with actual group64 permutation; actual `torch.ops._C.marlin_gemm` |

Every path transports the activation once: `z=BF16(FP32(x)*beta_inv)`.
Beta is neither applied twice nor folded into the reconstructed weight.
D0's two multiplications are not reassociated. D0–D1 therefore includes
both reconstruction arithmetic and combined-scale representation. D1–P
contains remaining dequantization, rounding and execution differences; it is
not a pure estimate of reduction order. D0–P is their vector sum, which can
contain a negative cross term. A smaller final error does not imply that both
component errors are individually small.

Packed weights use INT4 storage with BF16 matrix multiplication. This is not
native INT4 MMA or the original DualQuant author's W4A4 kernel. The adapter
verifies the installed named Marlin API instead of assuming positional API
compatibility. `use_fp32_reduce=True`, `use_atomic_add=False`; TF32 and both
BF16/FP16 reduced-precision reduction flags are disabled.

## R0 and R1

R0 uses the installed native Qwen3 implementation. RMS statistics are FP32,
but normalized values are cast to BF16 before multiplying the BF16 norm
weight. Native RoPE multiplies and adds BF16 values. Native rotary embedding
generation computes frequencies in FP32 and returns BF16 cos/sin.

R1 retains Q/K normalization, learned norm multiplication and RoPE products
and sums in FP32, then casts final Q/K to BF16. It promotes the *same native
cos/sin values*, without recalculating frequencies. Shape, head mapping,
rotation pairs, epsilon, final strides and contiguity are checked. The patch
is scoped to a worker/model context and restored afterward. V, SDPA, softmax,
residual, MLP, cache and GEMM do not change. The intervention is the combined
Q/K norm–RoPE region, not RoPE alone.

Both D1 and P already share R0. Thus an R1 effect here is propagation
sensitivity, not evidence that previously different attention boundaries
were aligned. `ALIGNMENT_SUPPORTED` requires separate evidence of such a
pre-existing mismatch and is not inferred from a smaller KL.

## Comparison spaces and statistics

Full-path block outputs use the same layer/token/hidden coordinates but
have their own upstream histories. Local replay instead gives all six
conditions exactly the same saved D0_R0 block input and native position,
cos/sin/mask context. Full-path and local statistics are separate.

`relative_RMSE = sqrt(SSE/reference_energy)`. Zero reference energy is
UNDEFINED; absolute error remains available. Local checkpoints include q/k
projection, norm, RoPE, attention output before o_proj, o_proj, MLP and block
output. The optional single-boundary replacement is recorded separately;
omission does not create replacement results.

The primary estimand is document-mean `KL(D1_R0||P_R0) - KL(D1_R1||P_R1)`
on EVAL512. Each document has equal weight after averaging its 16 selected
positions. The CPU calculation uses FP64 full-vocabulary normalization.
The paired percentile bootstrap resamples 24 documents, 10,000 times, seed
61027023. It is descriptive uncertainty for this synthetic corpus, not a
simultaneous guarantee or a model quality assessment.

The layer score uses all DEV512 block-output tokens. Top2 selection and
`tau_abs=max(1e-10,10*r_repeat)` are locked before EVAL. A historical 2% gate
failure is retained as a diagnostic outcome, not relaxed or used as a reason
to tune the artifact.

Cost workers remove hooks/dumps and repeat one DEV512 input. Same-call host
timing includes CUDA event recording and completion wait. Event elapsed is
stream time, not kernel busy time. Parent worker wall includes imports, load,
context, setup, calls and exit. Neither timing is TTFT, TPOT or serving rate.

The R0 measurement context retains a no-op Python dispatch wrapper around the
native arithmetic. Full logits are bit-identical to the unwrapped native path
in the validation inputs; this is not a claim of zero wrapper cost. Cold calls
are the first call of each R mode in one loaded model: R1 follows R0, so R1 is
not a fresh-process/context cold start.
