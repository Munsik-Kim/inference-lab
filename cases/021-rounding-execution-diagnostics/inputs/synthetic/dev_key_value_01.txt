Greenhouse ventilation sheet
Purpose: Specify how a grower records ventilation decisions in separate growing zones.
This is an invented example with no real people, facilities, or measurements. The numeric values are illustrative, not operating advice.
Operating rule: Ventilation responds to measured leaf and air conditions. A dry sensor must be inspected before an irrigation cycle is added to the schedule.

record_format = sectioned key-value register
review_policy = retain original observations and append corrections
