Laboratory freezer audit
Purpose: Define independent checks for cold storage and specimen identity.
This is an invented example with no real people, facilities, or measurements. The numeric values are illustrative, not operating advice.
Operating rule: An alarm acknowledgement never substitutes for a temperature recovery record. A moved vial keeps its original identifier and receives a separate location history.

record_format = sectioned key-value register
review_policy = retain original observations and append corrections

next_action = Compare alarm_delay with the applicable operating limit, record the result, and assign a follow-up for rack_one when evidence is incomplete.
