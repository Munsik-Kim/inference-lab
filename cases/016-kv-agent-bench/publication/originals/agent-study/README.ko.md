# Case016 — 작은 KV 캐시로 더 많은 업무를 정확히 끝낼 수 있을까?

여러 자료를 읽어 필요한 버전을 고르고, 금액 계산·기록 수정·검증까지 맡기는 합성 업무입니다.

실제 압축 KV를 사용하는 vLLM과 장문 업무 실행·감사 도구를 구현했습니다. 고정한 DEV 96개 조건에서 B16은 0/48, NVFP4는 6/48의 검증된 업무 성공을 기록했습니다. 같은 12개 과제를 메뉴·응답 한도 4개 조건으로 반복한 결과입니다. 기준선 확대 gate는 NOT_MET입니다. 이번 범위 밖의 P2/P3는 미실행입니다.

먼저 알아둘 말: KV 캐시는 모델이 읽은 내용의 중간 계산 결과를 저장하는 공간입니다. 가중치는 모든 조건에서 BF16이고 KV 저장 형식만 비교합니다. 금액은 소수점 없는 최소단위 정수입니다. 예를 들어 개수×한 개 가격에 정수 할인 규칙을 적용합니다.

실제 구현: 긴 근거와 도구 메뉴 생성 → raw SSE/token 관측 → 격리된 도구 실행 → 상태·관측 순서·최종 답 채점 → 새 fixture에서 CPU 재생.
