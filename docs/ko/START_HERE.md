# DIOVA 처음 보기

[English](../en/START_HERE.md) | 한국어 · [홈](../../README.ko.md)

## 1. 무엇을 하는 프로젝트인가요?

AI 모델을 더 가볍거나 빠르게 바꿨을 때 계산과 답변이 어떻게 달라지는지 조사합니다. RTX 5080에서 비교 실행 도구, 모델의 행렬을 줄이는 코드, 입력별 결과 탐색기를 만들고 측정했습니다. 보고서를 읽고 저장된 화면을 보는 데 AI 전공 지식이나 GPU는 필요 없습니다.

## 2. 왜 빠르게 만들기 어려운가요?

모델은 여러 계산을 이어서 실행합니다. 한 계산을 줄여도 데이터를 바꾸어 준비하는 시간이 추가되거나 다른 계산이 대부분의 시간을 차지할 수 있습니다. 그래서 작은 연산의 시간과 모델 전체의 시간을 따로 잽니다. 숫자를 적은 비트로 표현하거나 계산의 일부를 제거하는 방법도 각각 비교합니다.

## 3. 속도와 정답률은 왜 따로 보나요?

빨라진 계산이 이전과 똑같은 값을 주지는 않을 수 있습니다. 반대로 값이 달라져도 선택한 답은 같을 수 있습니다. 전체 정답 수가 비슷하더라도 새로 맞힌 질문과 틀리게 된 질문이 서로 다를 수 있습니다. 답변을 비교할 때는 별도로 계산한 정답(gold)과 기준 모델의 답을 함께 보며, 정답에 준 확률도 확인합니다.

## 4. 일곱 사례는 어떻게 이어지나요?

실행 문제에서 출발해 숫자 표현, 비용, 답변, 구조 압축으로 질문을 넓혔습니다. 조건이 다른 독립된 사례들을 읽는 순서입니다.

- [001 실행](CASEBOOK.md#case-001): 기존 경로 수정 전후에 모델이 작동하는지 확인.
- [002 숫자 표현](CASEBOOK.md#case-002): 공식 두 모델의 메모리·시간·문서 추출 비교.
- [003 수치 근사](CASEBOOK.md#case-003): 계산을 근사할 때 기준에 따른 오차 검사.
- [004 호출 비용](CASEBOOK.md#case-004): 준비 작업까지 포함하면 빠른지 측정.
- [005 설정 비교](CASEBOOK.md#case-005): 속도와 오차를 함께 만족하는지 검사.
- [006 답변](CASEBOOK.md#case-006): 같은 질문의 점수와 선택 변경 추적.
- [007 구조 압축](CASEBOOK.md#case-007): 일부 행렬을 실제로 줄이고 결과 비교.

## 5. 두 사례부터 살펴보세요

**Case 007:** 모델 안에서 정보를 변환하는 큰 블록인 MLP 하나를 16그룹으로 나눴습니다. 그룹을 따로 평가하거나 서로의 상호작용까지 보고 제거 대상을 골랐습니다. 행렬을 실제로 잘라 작은 블록을 만든 뒤, 선택에 쓰지 않은 입력 192개로 검사했습니다. 25% 제거에서는 상호작용 선택이 원래 출력에 조금 더 가까웠고, 50%에서는 같은 구조를 골랐습니다. 블록 자체는 빨라졌지만 전체 모델의 가속은 뚜렷하지 않았습니다. 원래 출력에 가까운 정도와 정답 확률 점수도 다른 결과였습니다. [정확한 결과](CASEBOOK.md#case-007).

**Case 006:** 질문의 정보를 조합하는 attention 연산 한 곳을 바꾸고, 같은 질문의 점수와 네 가지 보기 중 고른 답을 비교했습니다. 두 설정은 표준 192개 중 각각 5개·8개의 선택을 바꿨습니다. 그 집합에서는 기준선의 정답을 잃지 않았지만, 별도 스트레스 집합에서는 잃은 경우가 있었습니다. 후속 진단은 같은 입력에서 최고점 동률과 마지막 단어 점수 계산을 살폈습니다. 원래 실험과 별도로 표시됩니다. [입력별 결과와 한계](CASEBOOK.md#case-006).

[다운로드·열기 안내](GETTING_STARTED.md#offline-explorers)에서 ZIP을 받아 압축을 풀고 HTML을 브라우저로 여세요. 기존 탐색기 UI는 영어이며 저장된 결과를 보여줍니다. GitHub의 HTML 소스 화면과 구분하세요. 모델을 새로 실행하지 않습니다.

## 7. 구현과 자세한 설명은 어디에 있나요?

- **특정 연산만 어떻게 바꾸나요?** [Case 006 개입 코드](../../cases/006-attention-decision-stability/src/intervention.py)는 정한 층을 바꾸고 종료·예외 때 원래 경로를 돌려놓습니다.
- **실제로 어떻게 작아지나요?** [Case 007 행렬 축소 코드](../../cases/007-interaction-aware-mlp-pruning/src/surgery.py)는 같은 채널 인덱스를 관련 행과 열에 적용합니다.
- **기록을 어떻게 다시 확인하나요?** [CPU 재분석 안내](GETTING_STARTED.md#cpu-checks)는 공개 기록의 검사와 모델 재실행을 나누어 안내합니다.

모르는 말은 [용어집](GLOSSARY.md), 수치·조건은 [사례 안내](CASEBOOK.md), 구현 기여·원저자 출처는 [포트폴리오](PORTFOLIO.md)에서 이어서 읽을 수 있습니다.
