# Case 012 — 완료한 사람 평가

사용자가 이미지 체크를 완료했습니다. 직접 체크한 100장의 답을 같은 요청의 비슷한 사진 92장에도 적용했고, 전체 192장에 답이 있습니다.

## 확인한 결과

| 설정 | 모든 조건 충족 | 충족률 | 전체 요청 시간 중앙값 |
|---|---:|---:|---:|
| L1 / S89 | 52/64 | 81.25% | 4.534 s |
| L2 / S66 | 51/64 | 79.69% | 4.385 s |
| L4 / S50 | 53/64 | 82.81% | 4.762 s |

L4는 같은 입력에서 4개를 얻고 3개를 잃었습니다. 순차이는 1장(1.5625%p)입니다. 두 설정 모두 맞힌 입력은 49개, 모두 못 맞힌 입력은 8개입니다.

기록된 요청 시간 중앙값은 L2가 가장 짧았습니다. 이번 묶음 평가에서 L4는 L1보다 1장, L2보다 2장 더 조건을 맞혔습니다. 측정 시간이 서로 달라, 정확히 같은 시간의 비교는 아닙니다.

## 어떤 요청이 어려웠나요?

| 요청 종류 | L1 | L2 | L4 |
|---|---:|---:|---:|
| 개수 | 13/16 | 12/16 | 13/16 |
| 대상별 색 | 15/16 | 14/16 | 15/16 |
| 좌우 | 16/16 | 16/16 | 16/16 |
| 복합 조건 | 8/16 | 9/16 | 9/16 |

복합 요청이 가장 어려웠고, 모든 조건을 맞힌 이미지는 약 절반이었습니다. 이 체크리스트는 개수·요청한 색·공간 관계를 평가합니다. 알아볼 수 있는 물체의 형태가 자연스러운지, 사진이 사실적인지는 별도 점수에 포함하지 않습니다.

## 답을 어떻게 집계했나요?

전체 480개 항목 답 중 직접 체크는 254개, 묶음 적용은 226개입니다. annotations.json에 이미지·묶음·답을 가져온 원본의 ID를 보존했습니다. 묶음은 작업량을 줄이는 기능이며 서로 다른 PNG가 동일하다는 뜻은 아닙니다.
판단 불확실인 항목 3개는 미충족으로 계산했습니다. 불확실도 충족으로 가정하는 보조 계산에서는 52/64·53/64·54/64가 됩니다. 이는 민감도 계산이며 기존 체크를 바꾸지 않습니다.
답이 있는 192장은 192번의 독립적인 사람 판독과 같지 않습니다. 묶음 답안에는 신뢰구간이나 통계적 우위 주장을 붙이지 않았습니다. 문장 16개마다 초기 잡음 4개를 사용해 세 설정을 비교했습니다. 평가자는 기존 공개 사이트를 볼 수 있었으므로 독립된 완전 블라인드 평가라고 부르지 않습니다.

## 보존된 AI 평가와 비교

기존 AI 평가는 51/64·53/64·53/64로 보존했습니다. 사람과 AI의 이미지 통과 여부가 다른 것은 11/192장, 항목 답이 다른 것은 19/480개입니다. 이는 판단 차이이며 어느 평가자의 정답률을 검증한 수치가 아닙니다.
