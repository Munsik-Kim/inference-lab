  1. 메모리에 올라가는가?

    가중치 외에도 대화 기록을 처리하는 캐시와 작업 공간이 필요합니다. 파일이 작아졌다고 모든 16GB GPU에서 같은 길이로 실행되는 것은 아닙니다.

  2. 실제 요청을 더 빠르게 처리하는가?

    입력 길이, 생성 길이, 동시에 보내는 요청 수, 실행 엔진을 맞춰 비교합니다. 처음 응답할 때까지의 대기와 전체 완료 시간도 구분합니다.

  3. 내 업무를 정확하게 수행하는가?

    원본과 비슷한 답인지, 정답인지, 실제 도구 작업까지 끝났는지는 다릅니다. 빠른 설정이라도 업무별 실패가 남을 수 있습니다.

측정 방법과 결과 읽는 법에서 지표와 검증 범위를 먼저 확인할 수 있습니다.
