이 안내서는 제가 구현한 모델 압축·실행 검사·답변 비교 작업을 설명합니다. 채용 담당자는 구현과 한계를, 서비스를 검토하는 분은 확인된 사용 범위를, AI가 익숙하지 않은 개발자는 필요한 입력과 결과물을 볼 수 있습니다. 결과를 읽는 데 GPU는 필요하지 않습니다.

양자화는 모델의 숫자를 더 적은 비트로 저장하는 방법입니다. 저장 공간을 줄여도 답변과 속도는 따로 확인해야 합니다. 양자화 용어 설명

내가 확인하려는 것은 무엇인가요?

  1. 메모리에 올라가는가?

    모델이 학습한 숫자(가중치) 외에도 이전 문장의 계산을 재사용하는 메모리(KV 캐시)와 임시 작업 공간이 필요합니다. 파일이 작아졌다고 모든 16GB GPU에서 같은 길이로 실행되는 것은 아닙니다.

  2. 실제 요청을 더 빠르게 처리하는가?

    입력 길이, 생성 길이, 동시에 보내는 요청 수, 실행 엔진을 맞춰 비교합니다. 처음 응답할 때까지의 대기와 전체 완료 시간도 구분합니다.

  3. 내 업무를 정확하게 수행하는가?

    원래 언어 모델(LLM)과 비슷하게 답했는지, 별도로 정한 정답을 맞혔는지, 실제 파일 수정 같은 작업까지 끝냈는지를 각각 확인합니다. 빠른 설정이라도 업무별 실패가 남을 수 있습니다.

측정 방법과 결과 읽는 법에서 지표와 검증 범위를 먼저 확인할 수 있습니다.
