English introduction

Run and check an AI model on a 16GB GPU

Work on reducing model files, running answers and investigating failures on an RTX 5080.

This guide explains what I built for language model (LLM) compression, execution checks and answer comparison. Recruiters can review implementation and limits; people considering a service can see what was verified; developers new to AI can follow the inputs and outputs. No GPU is needed to read the evidence.

The complete practical guide is currently in Korean. These English pages provide a short introduction and key findings; they are not a full translation.

Three separate questions

  1. Does it fit?

    The model’s learned numbers (weights), memory for reusing earlier text calculations (KV cache), and temporary workspace all take space. A smaller file alone does not prove the model will fit.

  2. Does it serve requests faster?

    Compare the same input/output lengths, simultaneous request limits and running program. Waiting for the first answer, total text produced per second, and time to finish a request answer different questions.

  3. Does it do the job correctly?

    Check separately whether answers match the original model, match independently defined correct answers, and complete the real tool action such as editing a file.

How to read the measurements

Qwen3-4B-Instruct-2507 — English summary

Cases008 Q and 009 run four-bit compressed weights with GPTQ/vLLM. Case002 extracts document facts with an official eight-bit (FP8) model. Case013 restores four-bit values to a 16-bit format (BF16) for comparison calculations (reference), then checks answers and tool failures.

Some answers became wrong, some programs exited abnormally, and the full-model calculation check for direct compressed execution (packed) failed. These are results from one RTX 5080, not support for every 16GB GPU.

Keep comparisons separate

Comparing different models helps choose a model for a task. Comparing number formats or saved model files of the same model family helps assess compression. This guide is not a cross-model leaderboard. The official BF16/FP8 model files come from external releases; their conversion histories were not independently controlled.
