English introduction

Using an LLM on a 16GB GPU

Model-specific quantization, serving, failures and mitigations observed on an RTX 5080.

For developers running open-weight models locally, teams considering model changes or automation, and readers reviewing the implementation. No GPU is needed to read the evidence.

The complete practical guide is currently in Korean. These English pages provide a short introduction and key findings; they are not a full translation.

Three separate questions

  1. Does it fit?

    Weight files, GPU allocations, KV cache and workspace are different resources.

  2. Does it serve requests faster?

    Match input/output lengths, concurrency and engine policy. First response, token throughput and completion latency measure different boundaries.

  3. Does it do the job correctly?

    Baseline agreement, gold accuracy and actual tool execution are different outcomes.

Keep comparisons separate

Comparing different models helps choose a model for a task. Comparing precision or deployment artifacts of the same model family helps assess compression. This guide is not a cross-model leaderboard. Official BF16/FP8 artifacts are not an independently controlled upstream conversion experiment.
