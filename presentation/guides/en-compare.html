Baseline JSONL · Candidate JSONL. From the repository root, use Python 3.10+ with fresh environment/output paths:

Expected: PASS with 4 records for each validation, PASS with 4 pairs for comparison, exit 0. Generates report.md, report.json and pairs.csv. No model, Torch, CUDA or NumPy is needed; installation may fetch Python build tools. Shell paths above are Linux/macOS; Windows can use the same CLI arguments in a separate Python environment.

2. Equal accuracy can hide a regression

Gold is the independent arithmetic sum. Answers are whitespace-stripped decimal integer strings.

Four synthetic pairs; separate from measured model results
ID / questionGoldBaseline → candidateTransition
sum-01 / 2 + 244 → 5Lost correct answer
sum-02 / 3 + 587 → 8Gained correct answer
sum-03 / 6 + 176 → 9Different wrong answer
sum-04 / 4 + 599 → 9Both correct

Both score 2/4. The report separates correct_to_wrong=1, wrong_to_correct=1, wrong_to_wrong=1, all_answer_disagreement=3. Use report.md for the task summary, report.json for configuration and all pairs, pairs.csv for individual changes. Four synthetic pairs and their descriptive intervals do not rank real models.

3. Map your own saved records

Source values → schema version 1
SourceFields
Dataset / version / item keytask, task_version, sample_id
Exact shared input ruleprompt_hash: SHA256 of UTF-8 input, including system/template text under the same rule
Independent gold and gradinggold, gold_definition: identical accepted strings and extraction/normalization rule
Model / checkpoint identitymodel_id, artifact_id: one combination per file
Extracted answer / caller gradingoutput_type: extracted_answer, answer, boolean correct
Provenance / formatevidence_kind: measurement / historical / synthetic_test; integer schema_version: 1
Optional source statusprocess_exit_code: integer on all rows of both files, or omitted throughout

Compute hashlib.sha256(prompt.encode("utf-8")).hexdigest(). The CLI compares identifiers, without authenticating actual prompts or artifact bytes. Free-form correctness is caller-supplied, not automatic grading.

For basic answer comparison, omit distribution and scores. Full-vocabulary probabilities/logits are not required. Compatible optional distributions enable additional diagnostics. Validate each file, then replace the compare input paths. Keep private inputs out of shared reports. There is no browser upload step.

4. Reject different questions or gold rules

Changing only the first candidate prompt_hash to "0" * 64 gives pair mismatch: prompt_hash, exit 2, with no report directory. Changing gold_definition gives pair mismatch: gold_definition. Each file may validate alone while pairing fails. The --intersection option does not repair a changed input contract.

5. Technical judgment: current design

  • Chosen: separate paired losses/gains/disagreement and retain source failure status.
  • Alternative: mean accuracy alone hides the example’s regression.
  • Evidence: core and contract tests.
  • Limit / next criterion: callers must validate grading and identity rules for their task. This describes the current design, not another historical alternatives experiment.
