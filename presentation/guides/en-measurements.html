How to read the measurements

Complete explanation in Korean. Definitions for existing research terms remain in the shared glossary.

Files and GPU memory

Weight file bytes measure disk storage. Torch allocator peaks measure one allocator's recorded allocations. Whole-device sampled peaks include other processes and can miss short spikes. GB = 10⁹ B, GiB = 2³⁰ B, MiB = 2²⁰ B. Do not exchange these scopes or units.

Waiting, generation and completion

TTFT is time to the first response (first choice SSE in Case009). TPOT measures time per subsequent output token. Output throughput divides total output tokens by the measurement interval and can include concurrent requests. Full request latency includes preparation, waiting, generation and transport.

Fixed-length timing matches input/output lengths and concurrency; free-generation quality has its own gold, parser and length cap. Shorter output can finish sooner without faster token generation.

Agreement, accuracy and actual work

Baseline agreement is not gold accuracy. A final success JSON is not evidence that a tool ran. The agent checks require actual tool events and the expected fixture state. Model-file creation is also not proof of a working low-bit kernel; reference execution may dequantize to BF16.

Evidence and execution states

Keep direct measurements, reanalysis of saved records and theoretical calculations distinct. A policy-skipped run is unexecuted, not an observed out-of-memory error. Abnormal process finalization after saved calculations is a process failure. A clean execution can still have quality regressions.

Repetitions do not add independent tasks

Eight tasks repeated under ten conditions produce 80 episodes, not 80 independent tasks. Already observed DEV cases do not become held-out data when rerun. Case009's intervals resample three paired server rounds, not independent concurrent requests.

Preserve the execution boundary

Case013's BF16 reference quality cannot be combined with another path's kernel speed, especially while its packed full-model numeric gate failed. Read the exact model, revision, artifact, engine, workload and process exit before applying a result.
